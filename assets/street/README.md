# پک فوتبال خیابونی

مدل‌های low-poly دست‌ساز برای فوتبال توی کوچه. همه جدا اینجاست تا
شخصی‌سازی راحت باشد — هیچ فایلی بیرون این پوشه به این پک وصل نیست.

## چی توشه

**وسایل (`props/`)** — هر مدل یک `.obj` + یک `.mtl` هم‌نام:

| فایل | چیه | اندازه |
| --- | --- | --- |
| `goal_small` | دروازه کوچک فلزی | ۱٫۶ × ۱٫۱ متر |
| `cone` | مخروط ترافیکی | ۲۵ سانت |
| `tire_stack` | سه لاستیک روی هم + یکی تکیه‌داده | — |
| `brick_stack` | یک توده آجر (دو تا بذار = دروازه آجری!) | — |
| `bench` | نیمکت چوبی | ۱٫۴ متر |

**بچه‌ها (`kids/`)** — قد ≈ ۱٫۱ متر، رو به `+Z`:

| فایل | کیه |
| --- | --- |
| `kid_ali` | کاپیتان: کلاه قرمز، پیراهن راه‌راه قرمز/سفید، شلوارک آبی |
| `kid_reza` | پابرهنه با پیراهن سبز و شلوارک خاکی |
| `kid_hassan` | قدبلند: پیراهن زرد و شلوار تیره بلند |

## شخصی‌سازی

- **رنگ:** هر `.mtl` را با ادیتور باز کن و عددهای `Kd` (قرمز سبز آبی،
  از ۰ تا ۱) را عوض کن. اسم متریال‌ها (`shirt`، `skin`، ...) را عوض
  نکن، مگر اینکه `.obj` را هم هماهنگ کنی.
- **شکل و اندازه:** همه‌چیز از `Tools/make_street_models.py` ساخته
  می‌شود — عددها را عوض کن و دوباره اجراش کن:
  `python3 Tools/make_street_models.py`
- **چیدمان:** دنیای نمونه `Worlds/street_kids.kimia` را باز کن؛
  مدل‌ها با `meshfile` وصل‌اند و با bring-in هم می‌شود آوردشان.

## دو نکته

- بچه‌ها **مجسمه‌اند، نه بازیکن**: اسکلت ندارند، پس کلیپ‌های
  `assets/animations` رویشان نمی‌نشیند — ولی می‌شود کنارشان آدمک
  انیمیشنی هم آورد.
- اسم آبجکت‌ها آزاد است، **به‌جز** پیشوندهای موتور: `Goal` (دروازه
  فیزیکی)، `Ball` (توپ بازی)، `Player`، `Wall_` و `Block_`.
  برای همین دروازهٔ اینجا `MiniGoal` نام دارد، نه `Goal`.
