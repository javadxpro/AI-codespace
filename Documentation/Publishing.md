# انتشار — دادن بازی به دیگری

تا اینجا می‌شد بازی ساخت ولی نمی‌شد آن را به کسی داد. حالا می‌شود.

## در Workbench

دکمهٔ **Publish** بالای صفحه. یک پوشه می‌سازد با سه فایل:

| فایل | چیست |
|---|---|
| `game.kimia` | **کل بازی**: صحنه، اجسام، فیزیک، قواعد، متغیرها، صفحهٔ بازی |
| `play.sh` | یک خط برای اجرا — بازیکن نباید هیچ گزینه‌ای بلد باشد |
| `README.txt` | سه قدم |

بعد `kimia_world` را کنارشان کپی می‌کنی و تمام. یک فایل بازی، یک برنامه.

## بازیِ منتشرشده ویرایشگر ندارد

کسی که بازی را به او می‌دهی **بازیکن** است، نه ویرایشگر. هر دکمهٔ ویرایشی
روی صفحه راهی است برای خراب کردن چیزی که ساخته‌ای. پس در حالت انتشار:

- **مستقیم وارد بازی می‌شود** — نه منو، نه سازنده، نه فهرست اجسام.
- **`/bench` وجود ندارد** (۴۰۴) و لینکش روی صفحه نیست.
- **API ویرایش جواب نمی‌دهد** — اگر فقط صفحه را برمی‌داشتیم، پنهان‌کاری
  بود نه امنیت.
- **دکمهٔ «منو» از پدها حذف می‌شود** — فقط کنترل‌های بازی می‌ماند.

## چرا یک فایل کافی است

فایل دنیا از قبل **همه‌چیز** را نگه می‌دارد: صحنه، کامپوننت‌ها، استخوان‌ها،
قواعد، متغیرها و پنل‌ها. پس انتشار چیز تازه‌ای اختراع نمی‌کند — همان چیزی را
می‌نویسد که ذخیره می‌نوشت، به‌علاوهٔ راهی برای اجرا.

## اجرا

```bash
bash play.sh          # روی ۸۰۸۰
bash play.sh 9000     # یا هر پورتی
```

سپس در مرورگر: `http://127.0.0.1:8080`
