# صفحهٔ بازی — رابط کاربری خودِ بازی

HUD داخلی موتور یک ستون متن در گوشه است: برای مسابقهٔ فوتبالی که خود موتور
نوشته خوب است، برای بازیِ **تو** بی‌فایده. حالا خودت می‌گویی نوار جان کجا
باشد و از کدام متغیر پیروی کند.

## چهار نوع پنل

| نوع | کار |
|---|---|
| **label** | متن |
| **bar** | نوار پرشونده (جان، انرژی) |
| **box** | مستطیل ساده؛ پس‌زمینه یا قاب |
| **button** | متنی که فشار داده می‌شود و **رویداد** بلند می‌کند |

## متن زنده

متن پنل با آکولاد متغیر می‌خواند:

```
SCORE {score}      →      SCORE 1250
```

بدون یک خط کد. اگر متغیر وجود نداشته باشد، **جایش خالی می‌ماند** نه اینکه
آکولادها را به بازیکن نشان بدهد — اشتباه تایپی باید غلط به نظر برسد، نه
خراب.

## مکان با کسر، نه پیکسل

`x`، `y`، `w`، `h` همه بین ۰ و ۱‌اند. چیدمانی که روی گوشی ساخته‌ای روی
دسکتاپ هم درست است و با تغییر اندازهٔ پنجره به‌هم نمی‌ریزد.

## دکمه‌ها به قواعد وصل می‌شوند

دکمه رویدادی بلند می‌کند که هر قاعده‌ای می‌تواند به آن گوش بدهد:

```
[دکمه "+10"]  رویداد: bonus
WHEN event bonus   DO add score 10
```

دو تصمیم: **پنل رویی برنده است** (کاربر دکمه‌ای را می‌زند که می‌بیند)، و
**برچسب دکمه نیست** هرچقدر هم شبیهش باشد.

## پنهان کردن

هر پنل `visible` دارد، پس قاعده می‌تواند صفحهٔ پیروزی را فقط در پایان نشان
بدهد.
