# معماری KIMIA

این پروژه به‌صورت مرحله‌ای و از پایین به بالا ساخته می‌شود. لایه‌های فعلی:

- **هستهٔ مستقل**: انواع عددی، گزارش‌گیری، پروفایلینگ و زمان‌بندی گام ثابت.
- **ریاضیات** (header-only): بردارها، ماتریس‌های ستون‌عمدهٔ راست‌دست، کواترنیون، دوربین.
- **گرافیک**: `MeshData`، پریمیتیوها (مکعب ۲۴v/۳۶i، صفحه ۴v/۶i، کرهٔ مرجع 153v/768i)، لودر OBJ.
- **خط لولهٔ دارایی**: FBX (ufbx)، تصویر PNG/JPG (stb)، صدا WAV/MP3 (dr_libs) + ابزار `kimia_assets`.
- **صحنه**: موجودیت‌ها با هندل ۱-مبنا + SceneIO (فرمت متنی v1 با بارگذاری مقاوم).
- **فیزیک**: گام ثابت ۱/۱۲۰ با سقف انباشتگر، کرهٔ دینامیک در برابر صفحه و AABB استاتیک.
- **رندرینگ**: GL 3.3 از طریق لودر dlopen (بدون هدر) + EGL pbuffer، سایهٔ PCF،
  و رسترایزر نرم‌افزاری z-buffer به‌عنوان مسیر تضمینی.
- **پلتفرم**: ورودی (LEVEL/EDGE) و پنجرهٔ اختیاری SDL2 با حالت پنهان.
- **برنامه**: بوت‌استرپ Engine و WebViewer — سرور وب بدون وابستگی برای
  نمایش و کنترل فریم‌ها از مرورگر (localhost:8080).

## قرارداد ساخت

```bash
cmake -B build -DKIMIA_WERROR=ON
cmake --build build -j4
ctest --test-dir build --output-on-failure
```

هر زیرسیستم قبل از رفتن به مرحلهٔ بعدی تست مستقل دارد و با هشدار صفر ساخته می‌شود.
