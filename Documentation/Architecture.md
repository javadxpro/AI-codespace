# معماری KIMIA

این پروژه به‌صورت مرحله‌ای و از پایین به بالا ساخته می‌شود. نخستین مرحله، هستهٔ مستقل از پلتفرم است: انواع عددی، گزارش‌گیری، پروفایلینگ و زمان‌بندی گام ثابت.

## قرارداد ساخت

```bash
cmake -B build -DKIMIA_WERROR=ON
cmake --build build -j4
ctest --test-dir build --output-on-failure
```

هر زیرسیستم قبل از رفتن به مرحلهٔ بعدی تست مستقل دارد و با هشدار صفر ساخته می‌شود.
