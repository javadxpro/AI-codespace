# KIMIA World (Engine/World + Examples/WorldEditorApp)

ویرایشگر گزینه‌محور «مثل Unity» — کاربر **هیچ کدی نمی‌نویسد و هیچ کلیدی
لازم نیست بداند**: همه‌چیز منوها و گزینه‌های لمسی روی صفحهٔ WebViewer است.
مسیر پذیرش مشخصات:

**Create Project → Open KIMIA World → Create World → Add Player → Add Ball →
Add Environment → PLAY** — و نتیجه یک بازی واقعیِ قابل اجراست.

## جریان منوها (State Machine)

- **Main**: `دنیای جدید` / `باز کردن دنیا` / `خروج`.
- **Menu** (بعد از ساخت/بارگذاری): `افزودن بازیکن`، `افزودن توپ`،
  `افزودن محیط`، `بازی (PLAY)`، `ذخیره`، `منوی اصلی`.
- **Add Player** → می‌پرسد «بازیکن: چه سرعتی؟» → `سریع (6)` / `عادی (4)` /
  `آرام (2.5)` — پاسخ، سرعت واقعی حرکت بازیکن را تنظیم می‌کند.
- **Add Ball** → می‌پرسد **«توپ: دقیق باشه یا فانتزی؟»**:
  - `دقیق (مثل گلف)` → r=0.12، استرداد 0.40، اصطکاک 0.40، غلتش 0.22
    (دقیقاً ثابت‌های گلف)؛
  - `فانتزی (پران و لغزنده)` → r=0.15، استرداد 0.85، اصطکاک 0.05،
    غلتش 0.0 — پرش بلند، اصطکاک کم، بدون افت غلتش (تست اثبات می‌کند که
    توپ فانتزی بعد از ۳ ثانیه بیش از ۳ برابر سریع‌تر از توپ دقیق است).
- **Add Environment** → `چمنزار` / `شنی (کویر)` / `شب` — رنگ کف و آسمان.
- **PLAY** → شبیه‌سازی قابل اجرا: جهات (پد لمسی یا فلش‌ها) بازیکن را حرکت
  می‌دهند؛ برخورد با توپ آن را در همان جهت شوت می‌کند
  (`سرعت = 2 + سرعت بازیکن×0.5` + پرش کوچک)؛ عبور توپ از خط دروازه
  (z=−8.5، داخل تیرها، زیر ارتفاع 1.2) = **گل** → امتیاز +۱ و جشن ۲ ثانیه؛
  بعد توپ به مرکز برمی‌گردد. `توپ از نو` (r) و `منو` (b) روی پد هستند.

## ذخیره/بارگذاری (WorldIO)

- فایل دنیا یک فایل **معتبر SceneIO-v1** است؛ همهٔ پیکربندی‌ها در خطوط
  کامنت `#` ذخیره می‌شوند (`# world name`، `# player speed`،
  `# ball type`، `# env`، `# score`) که لودر v1 نادیده می‌گیرد.
- **فایل‌های قدیمی `.kimia` بدون این متادیتا با پیش‌فرض‌ها بار می‌شوند**
  (تست: نمونهٔ handoff بدون متادیتا → MyWorld/accurate/grass + موجودیت‌ها).
- خطاهای IO هرگز خاموش نمی‌مانند: در خط آمار به‌صورت `note` دیده می‌شوند.

## WebViewer (منوی پویا)

- `GET /menu` منوی فعلی را JSON برمی‌گرداند
  (`{"title":"...","holds":[[label,key],...],"taps":[...]}`)؛ صفحهٔ کنترل هر
  ۳۰۰ میلی‌ثانیه آن را می‌خواند و دکمه‌ها را بازسازی می‌کند — سؤال‌ها بدون
  رفرش صفحه عوض می‌شوند. منوی خالی = نمایش پد ثابت (سازگار با گلف و
  RemoteView). برچسب‌های فارسی بدون تغییر عبور می‌کنند (UTF-8).
- گزینه‌های هر منو به Num1..Num6 بسته شده‌اند (لمسی یا کیبورد فیزیکی
  1-6)؛ در بازی: فلش‌ها حرکت، r و b عمل.

## CLI

```
kimia_world [--port N] [--world <file.kimia>]     # پیش‌فرض: 8080 و my_world.kimia
```

## خط آمار

```
KIMIA WORLD | <MAIN|MENU|PLAYER|BALL|ENV|PLAY|GOAL> | world <name>
| player <fast|normal|slow> | ball <accurate|fantasy> | env <grass|sand|night>
| score <N>
```
