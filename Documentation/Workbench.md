# KIMIA Editor — رابط کاربری ویرایشگر

`http://127.0.0.1:8080/bench`

از نسخهٔ 0.27.0 چیدمان و اصطلاح‌ها از **Unity** آمده‌اند: همان سه ستون و
همان اسم‌ها، ولی هر خطِ HTML و CSS و جاوااسکریپت برای همین موتور از صفر
نوشته شده — هیچ کد، استایل یا دارایی از Unity در آن نیست. نشانی صفحه
(`/bench`) و نام همهٔ مسیرهای `/api/*` سر جایشان‌اند.

| نام | یعنی چه |
|---|---|
| **Hierarchy** | فهرست همه‌چیز در دنیا (چپ) |
| **Inspector** | پنل توصیف یک جسم (وسط) |
| **Game** | نمای زندهٔ بازی (راست، بزرگ) |
| **Toolbar** | ابزارها، Play/Pause/Step، اسنپ و ساخت جسم (بالا) |
| **Project** | فایل‌ها، پریفب‌ها و صحنه‌ها (پایین) |
| **Console** | کارهایی که ویرایشگر همین‌الآن کرد (پایین) |

## چیدمان

```
┌─ KIMIA Editor ─ [Select|Move|Rotate|Scale] ─ [Play|Pause|Step] ─ [snap] ─ [+ Create] ─ Rules ─ Publish ─ Game › ─┐
│ Hierarchy  │  Inspector   │                                                        Game                       │
│ Ground     │  Name        │                                                                                   │
│ Ball       │  Transform   │                                     (frame.png)                                   │
│ ● Model_1  │  Animation   │                                                                                   │
│            │  Body/Tags…  │                                                                                   │
├────────────┴──────────────┤                                                                                   │
│ Project: Files │ Prefabs │ Scenes              │  Console                                                     │
└───────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

روی گوشی به یک ستون تا می‌شود (Hierarchy با دکمه باز می‌شود).

نقطهٔ رنگی کنار هر ردیف می‌گوید چه فیزیکی دارد: آبی = جامد، سبز = متحرک،
خاکستری = فقط تزئین. کنارش هم شمارش برچسب/حرکت/صدا نوشته می‌شود.

## کار کردن با آن

۱. **ابزارها** — Select فقط انتخاب می‌کند؛ Move با درگ روی زمین
   می‌لغزاند؛ Rotate با درگ افقی می‌چرخاند و با درگ عمودی کج می‌کند؛
   Scale با درگ عمودی بزرگ/کوچک می‌کند. کلیدهای Q/W/E/R هم همان‌اند.
۲. **اسنپ** — وقتی روشن است، حرکت روی گرید می‌نشیند و چرخش با گام ۱۵
   درجه می‌پرد. عدد گرید از همان نوار ابزار عوض می‌شود.
۳. **پخش** — Play مستقیم می‌رود توی بازی؛ Pause فقط شبیه‌سازی را فریز
   می‌کند (منوها و سازنده زنده‌اند)؛ Step یک فریم جلو می‌رود. در برنامهٔ
   دسکتاپ: Return شروع، Tab توقف/ادامه، Backspace یک فریم. (Space عمداً
   پرش/شوت مانده چون اول بازی است بعد ویرایشگر.)
۴. **Inspector** — نام (با دکمهٔ Rename)، سه‌تایی Position/Rotation/Scale
   با عدد (چرخش به **درجه**)، رنگ، و بخش Animation: فهرست کلیپ‌های خودِ
   فایلِ آن جسم با دکمهٔ Play/Stop. بقیه (Body، برچسب‌ها، سیم‌کشی حرکت و
   صدا، استخوان‌ها، تست سیم) مثل قبل سر جایشان‌اند.
۵. **Hierarchy** — Duplicate (دکمه و Ctrl+D) و Delete (دکمه و کلید Delete).
۶. **ساخت جسم** — از نوار ابزار: Cube/Sphere/Plane (دکور ساده) یا
   Block/Wall/Goal/Crate/Hole/Player/Ball با پیش‌فرض‌های خود سازنده.
   Player و Ball تک‌موجودیتی‌اند: ساختن دوباره فقط جابه‌جاشان می‌کند.
۷. **Project** — فایل‌ها (List/Scan؛ کلیک روی نام مدل واردش می‌کند، روی
   عکس می‌نشاندش روی جسم انتخاب‌شده)، هر فایل دکمهٔ Rename (درجا) و
   Delete (با تأیید) دارد، و دکمهٔ Upload فایل را از کامپیوتر/گوشی توی
   پوشه می‌ریزد (روی نام تکراری نمی‌نشیند). بعد پریفب‌ها (Keep/Stamp) و
   صحنه‌ها.
۸. **Console** — هر کاری که می‌کنی با ساعت ثبت می‌شود؛ خط وضعیت موتور
   (آمار + کلیپ‌های در حال پخش) هم بالای آن است.

## معماری

صفحه هیچ‌چیز از موتور نمی‌داند. سرور درخواست را به لایهٔ `studio`
می‌دهد، آن از `WorldEditor` سؤال واقعی می‌پرسد، و JSON برمی‌گردد. یعنی هر
تصمیمی در موتور می‌ماند جایی که **تست‌پذیر** است، و صفحه فقط یک نما است.

مسیرهای قدیمی (همه کار می‌کنند): `/api/rack`, `/api/dossier`, `/api/place`,
`/api/paint`, `/api/fit-body`, `/api/label`, `/api/unlabel`, `/api/labelled`,
`/api/wire-motion`, `/api/wire-noise`, `/api/unwire`, `/api/bring-in`,
`/api/scrap`, `/api/pull`, `/api/pulse` و بقیه.

مسیرهای جدید ویرایشگر:

- `/api/object/create` (kind, x, z) — ساخت جسم، نام را برمی‌گرداند.
- `/api/object/duplicate` (name) — کپی درجا، نام کپی را برمی‌گرداند.
- `/api/object/rename` (name, to) — تغییر نام؛ Player/Ball/Ground رد می‌شوند.
- `/api/object/rotate` (name, dyaw, dpitch) — چرخش به **درجه**، چرخش جدید را برمی‌گرداند.
- `/api/object/scale` (name, factor) — مقیاس با ضریب، اندازهٔ جدید را برمی‌گرداند.
- `/api/object/euler` (name, x, y, z) — نوشتن چرخش به درجه.
- `/api/object/clips` (name) — `skeleton` و فهرست `clips` خودِ فایل.
- `/api/object/play-clip` (name, clip) و `/api/object/stop-clips` (name).
- `/api/transport/play` ،`/api/transport/pause` (paused) ،`/api/transport/step` ،`/api/transport/state`.
- `/api/asset/rename` (file, to) و `/api/asset/delete` (file)؛ آپلود با
  POST بدنهٔ خام به `/api/asset/upload?name=...` (سقف ۳۲ مگ). نام‌ها باید
  لخت باشند و بازنویسی ممنوع است.

`/api/dossier` حالا `"rotation"` (درجه) هم برمی‌گرداند و `/api/pulse` پرچم
`"paused"` — هر دو افزایشی‌اند؛ خوانندهٔ قدیمی چیزی نمی‌فهمد و نمی‌شکند.

مسیر ناشناخته یا نام اشتباه، `{"ok":false,"error":...}` برمی‌گرداند نه
خطای سرور — یک صفحهٔ قدیمی هرگز نباید موتور را قفل کند.

**صفحه کاملاً خودکفاست:** نه CDN، نه فونت بیرونی، نه فایل جانبی. روی گوشی
بدون اینترنت دقیقاً مثل دسکتاپ کار می‌کند.

## قفل‌ها

API روی نخ سرور اجرا می‌شود و حلقهٔ اصلی هم‌زمان دنیا را جلو می‌برد، پس هر
دو یک قفل می‌گیرند. حلقهٔ اصلی قفل را **قبل از** تماس با سرور رها می‌کند؛
اولین باری که این رعایت نشد، `/api/pulse` قفل کرد (lock-order inversion).
