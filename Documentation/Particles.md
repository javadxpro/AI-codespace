# ذرات — جرقه، دود و انفجار

بدون این‌ها بازی مثل چند جعبهٔ متحرک به نظر می‌رسد؛ با این‌ها مثل بازی.

## دستور، نه برنامه

یک **افکت** یک دستور غذاست: «شصت جرقهٔ نارنجی، به بالا، که در یک ثانیه محو
می‌شوند». چیزی بیش از این، یک زبان برنامه‌نویسی با لباس مبدل می‌شد.

| تنظیم | یعنی |
|---|---|
| `count` / `life` | چند ذره، و هرکدام چقدر بماند |
| `speed` / `spread` | چقدر تند، و **۰ = فوارهٔ مستقیم، ۱ = گلولهٔ کامل** |
| `gravity` | منفی = می‌افتد (جرقه)، مثبت = بالا می‌رود (دود) |
| `size` / `shrink` | اندازهٔ اول، و چقدر آب برود |
| رنگ اول و آخر | در طول عمر بین این دو محو می‌شود |

## در قواعد

کنشِ **effect** یک افکت را روی یک جسم — یا هر نقطه‌ای — پخش می‌کند:

```
WHEN collision Ball + Wall    DO effect explosion on Ball
```

بدون یک خط کد.

## سه تصمیم

- **جاذبه و مقاومت هوا مال هر ذره است، نه سیستم.** اگر مشترک بودند، دودِ
  بالارونده و جرقهٔ افتان نمی‌توانستند هم‌زمان وجود داشته باشند.
- **طول عمر تصادفی است** (۷۰٪ تا ۱۳۰٪). اگر همه یکسان بودند، انفجار مثل
  خاموش شدن یک کلید ناپدید می‌شد نه محو شدن.
- **پراکندگی قطعی است.** مولد تصادفِ خودمان است نه `<random>`، چون
  کتابخانهٔ استاندارد قول نمی‌دهد روی همهٔ ماشین‌ها یک نتیجه بدهد — و تکرار
  یک مسابقه باید همان فیلم باشد نه فیلمی دیگر.
