# فیزیک (Engine/Physics)

شبیه‌سازی برخورد گام‌ثابت برای بازی‌های KIMIA — کره‌های دینامیک در برابر
صفحه‌های استاتیک و جعبه‌های AABB استاتیک.

## مدل

- **گام ثابت** `dt = 1/120 s`؛ میزبان با نرخ دلخواه (مثلاً ۶۰ یا ۱۲۰ هرتز)
  از طریق انباشتگر (accumulator) با **سقف ۵ گام در هر فریم** پیش می‌رود
  (پشتوانه: `kimia::FixedTimeStep`). فریم خیلی کند نمی‌تواند شبیه‌سازی را
  مارپیچ کند.
- **گرانش**: شتاب `(0, −9.81, 0)`.
- **انتگرال‌گیری نیمه‌ضمنی (symplectic Euler)**: اول سرعت، بعد مکان — پایدار
  و دقیق برای سقوط آزاد:
  `y_N = y0 − g·dt²·N(N+1)/2`.
- **کره در برابر صفحه** (`y = const`، نرمال `+Y`): نفوذ ممنوع (تصحیح مکان)،
  بازتاب نرمال با `restitution`، اصطکاک مماسی و **اصطکاک غلتشی** روی مؤلفه‌های
  XZ در تماس.
- **کره در برابر AABB**: نزدیک‌ترین نقطهٔ جعبه به مرکز کره؛ اگر مرکز داخل
  جعبه باشد، خروج در راستای محور کمترین نفوذ. بازتاب نرمال با استرداد +
  اصطکاک روی مؤلفهٔ مماسی.

## API

- `PhysicsWorld(fixedDt = 1/120, maxStepsPerFrame = 5)`
- `addSphere / removeSphere / sphere(id)` — شناسه‌های **۱-مبنا**، هرگز
  بازاستفاده نمی‌شوند (۰ = null).
- `addPlane(y)` / `addBox(center, halfExtents)`
- `step()` — یک گام ثابت؛ `advance(hostSeconds)` — گام‌های سقف‌دار میزبان
  (تعداد گام اجراشده را برمی‌گرداند).
- `SphereBody`: `radius / restitution / friction / rollingFriction` با
  مقادیر پیش‌فرض گلف (۰٫۱۲ / ۰٫۴۰ / ۰٫۴۰ / ۰٫۲۲).
