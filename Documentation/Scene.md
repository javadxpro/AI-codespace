# سیستم صحنه و SceneIO (Engine/Scene)

## مفاهیم

- **EntityHandle**: شناسهٔ `u32` **۱-مبنا**؛ مقدار ۰ (`kNullEntity`) یعنی «هیچ». هندل‌ها هرگز
  دوباره استفاده نمی‌شوند — بعد از `destroy`، `get` بلافاصله `nullptr` برمی‌گرداند.
- **EntityData**: نام، `Transform` (موقعیت/مقیاس/چرخش)، نوع مش (`MeshKind`)، رنگ و زبری.
- **Scene**: نگهدارندهٔ موجودیت‌ها با API
  `create / destroy / get / alive / count / forEach / clear`؛ تکرار به ترتیب هندل
  (قطعی — برای سریال‌سازی پایدار). `demoShot` (اختیاری) شات دموی نویسندهٔ بازی را نگه می‌دارد.

## فرمت متنی v1 (SceneIO)

```text
# KIMIA scene v1
e "Green" mesh plane pos 0 0 0 scale 1 1 1 color 0.22 0.45 0.24 rough 0.95
e "Ball" mesh sphere pos 0 0 0 scale 1 1 1 color 0.95 0.95 0.92 rough 0.3
# demo 0.000000 0.610000
```

قواعد:

- خطوط `#` کامنت هستند، **به‌جز** `# demo <aim> <power>` که شات دمو را ذخیره می‌کند.
- `mesh` یکی از `cube` / `plane` / `sphere` است.
- نام موجودیت داخل گیومهٔ دوتایی است؛ escape ها: `\"` و `\\` (بارگذاری توکن بدون گیومه را هم می‌پذیرد).
- بارگذاری **مقاوم** است: کلیدواژه/توکن ناشناخته رد می‌شود، خط موجودیتِ ناقص نادیده
  گرفته می‌شود، کامنت‌های دموی ناقص بی‌اثرند.
- قالب‌بندی اعداد `%.9g` قطعی است؛ بنابراین **save → load → save بایت‌به‌بایت یکسان** است.
