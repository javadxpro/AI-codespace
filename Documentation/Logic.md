# منطق بصری — بازی‌سازی بدون کدنویسی

قلب قانون «قابلیت زیاد، بدون کدنویسی». یک بازی مجموعه‌ای از **قاعده**‌هاست
و هر قاعده جمله‌ای است که آدم بلند می‌گوید:

```
WHEN <چیزی رخ می‌دهد>   IF <این درست است>   DO <این کارها>
```

## چرا فهرست، نه گراف نود

گراف نودی روی صفحهٔ گوشی خوانا نیست، و تقریباً همهٔ منطق بازی واقعاً یک
**فهرست** «وقتی این، آن کار را بکن» است. فهرست از بالا به پایین اجرا می‌شود،
پس ترتیب چیزی است که **کاربر کنترل می‌کند** نه یک راز — و وقتی دو قاعده با
هم مخالف باشند، بالایی برنده است.

## رویدادها

`start` (یک‌بار)، `every-frame`، `key` / `key-held`، `collision`،
`area-enter` / `area-exit`، `timer`، `variable`، `event`.

سه نکته که با آزمایش واقعی تثبیت شدند:

- **`area-enter` یک‌بار شلیک می‌کند** نه هر فریمی که آنجا ایستاده‌ای؛ فرق
  «وقتی وارد شد» با «تا وقتی داخل است» تمام ارزش این رویداد است.
- **برخورد دوطرفه است**: «توپ به دیوار خورد» و «دیوار به توپ خورد» برای آدم
  یک اتفاق است.
- **تایمر آهنگ خودش را نگه می‌دارد**: به‌جای صفر کردن، مدت را کم می‌کند، پس
  یک فریم کند وقت را از دست نمی‌دهد.

## کنش‌ها

`set` / `add` (متغیر)، `move` / `move-to` / `rotate`، `spawn` / `destroy`،
`sound` / `animate` / `message`، `raise` (رویداد)، `wait`، `end-game`.

**رویدادی که یک قاعده بلند می‌کند، در همان فریم به قاعده‌های بعدی می‌رسد**،
پس زنجیره‌ای از چند قاعده یک‌جا حل می‌شود نه یکی در هر فریم.

## متغیرها

نوشتن روی متغیری که وجود ندارد، **می‌سازدش**. مجبور کردن کاربر به تعریف
قبلی، قدمی بی‌فایده است. خواندن متغیر حذف‌شده صفر می‌دهد، پس قاعده‌ای که به
چیز پاک‌شده اشاره کند بازی را نمی‌شکند.

## معماری: چه، نه چگونه

`LogicRuntime` می‌گوید **چه** باید بشود («توپ را ۰،۰،۵- ببر»، «صدای kick را
پخش کن») و دنیا آن را انجام می‌دهد. این جدایی یعنی همهٔ منطق بدون رندر، پنجره
یا فیزیک تست می‌شود — و همان قاعده‌ها هم پیش‌نمایش ویرایشگر و هم بازی
صادرشده را می‌گردانند.

## در Workbench

دکمهٔ **Rules** بالای صفحه. سه ستون: فهرست قاعده‌ها (با دکمه‌های
روشن/خاموش، بالا/پایین، حذف)، ساختن IF و DO برای قاعدهٔ انتخاب‌شده، و
متغیرها با وضعیت زندهٔ بازی.

هر قاعده به‌صورت جملهٔ خودش نمایش داده می‌شود:
`WHEN key space  DO add score 1  DO sound kick`

## مثال کامل، بدون یک خط کد

```
WHEN start                      DO set score 0
WHEN key space                  DO add score 1   DO sound kick
WHEN every-frame  IF score >= 3 DO message "YOU WIN"  DO end-game
```
