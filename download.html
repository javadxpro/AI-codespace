ویرایشگر جهان برای Termux — حدود ۲ مگابایت، بدون نیاز به اینترنت بعد از دانلود.

دانلود فایل ZIP
kimiya-world-editor.zip

بعد از انتقال به گوشی:

pkg install python unzip termux-setup-storage cd ~ unzip -o ~/storage/downloads/kimiya-world-editor.zip cd kimiya-world-editor python -m http.server 8080 --bind 0.0.0.0

بعد در مرورگر گوشی: http://127.0.0.1:8080
